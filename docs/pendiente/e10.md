## Hecho (bloque 3, parser XML) — `a609cb7`

- `bf-html/src/xml.rs` reescrito: XML 1.0 + Namespaces in XML con todas las WFC y NSC que
  aplican a un parser no validante; se detiene en el primer error. API: `parse_xml` (Result),
  `parse_xml_partial` (árbol hasta el error + error), `parse_xml_document` (para mostrar: lo
  parseado hasta el error), `parsererror_document` y `XmlError { message, line, column }`.

  markup, externas sin cargar, NDATA, `ELEMENT`/`ATTLIST`/`NOTATION` saltados, PE references),
  CDATA, PI, comentarios, referencias, normalización de atributos (§3.3.3), caracteres no

  HTML §14.2. `xml:space`/`xml:lang` quedan como atributos del namespace XML.
- `DOMParser.parseFromString` con tipos XML: error → documento con solo `parsererror` en
  `http://www.mozilla.org/newlayout/xml/parsererror.xml` (HTML §8.5.1).
- Tests: `bf-html/tests/xml.rs` (14). Comparación de DOM parser viejo/nuevo sobre los 6954
